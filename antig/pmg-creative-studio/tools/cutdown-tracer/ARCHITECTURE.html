Runtime flow — runPipeline(videoFile, trackId, deps) · pipeline.ts

1
Probe source duration
clipExtractor.probeDurationSec(videoFile)

ffmpeg reads the true length so we can clamp out-of-bounds model timestamps and bound extraction.

ClipExtractorffmpegffmpeg.ts→ durationSec
2
Select the best moments
selector.select({path}, {budgetSec:15})

Gemini ingests the video (Files API → poll ACTIVE) and returns ranked {startSec,endSec,score} via a structured-output schema.

VideoMomentSelectorGeminigemini.ts→ Segment[]
3
Clamp segments to the real duration
clampSegments(segments, durationSec)

Pure. Drops/clips moments past EOF (models can return timestamps beyond the video's end).

pureplanCuts.ts→ Segment[]
4
Fetch the track + resolve BPM
catalog.fetch(trackId)  then  tempo.detect(url)

Catalog returns a signed music URL + BPM from Firestore. If the doc has no BPM, librosa detects it. Catalog BPM wins; tempo is the fallback.

MusicCatalogFirestoreTempoDetectorlibrosafirestoreCatalog.ts · librosa.ts→ musicUrl, bpm
5
Plan the cuts on a beat grid
planCuts({bpm, totalSec:15, ranked})

Pure. Grid owns timing, content owns fill: a uniform bar grid (bar = 60/bpm·4) sets slot boundaries; ranked moments fill them (deduped, sliced when reused). Σ = exactly 15.000s.

pureplanCuts.ts→ CutPlan [{srcIn,srcOut,len}]
6
Extract each moment into a small clip
clipExtractor.extractClips(videoFile, plan, durationSec)

ffmpeg cuts one short H.264 clip per cut (audio stripped). The renderer can't ingest a long source — it only ever receives a few seconds of video.

ClipExtractorffmpegffmpeg.ts→ local clip paths[]
7
Host each clip for the renderer
blobStore.uploadAndSign(clipPath, name)

Uploads each clip to Cloud Storage and returns a fetchable getDownloadURL token URL (Shotstack pulls assets after queueing).

BlobStoreGCSstorage.ts→ ClipRef[] {url,len}
8
Render the reel
renderer.render(EditSpec)

buildShotstackTimeline lays the pre-trimmed clips end-to-end on a video track + the music on an audio track (1080×1920, 15s); submit → poll → playable MP4.

VideoRendererShotstackshotstack.ts→ mp4Url

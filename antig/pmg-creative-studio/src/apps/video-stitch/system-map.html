02 / M1 · STEP 1 — THIS DESIGN

Outpaint package + image reframe

The narrowest de-risking slice: make the outpaint capability importable from anywhere, then prove the tracer can turn an image into a clean 9:16 asset. No stitching or beat-timing yet.

A · Build _shared/ai into a consumable package — deploy-safe

  • Source of truth stays at functions/src/_shared/ai/ — functions keeps importing it directly, so the live ad-resizing deploy and code are untouched.
  • Add a package.json (name @pmg/ai-outpaint, exports/types → dist/) + a tsup build → ESM + .d.ts. sharp+zod = deps; openai+@google/genai = peerDeps (clients injected).
  • Build is opt-in (npm run build:ai). Functions never needs the dist — only cross-package consumers (the tracer, future video-stitch) do.

B · Reframer seam in the tracer

// new seam — one clear job, behind a Fake like every other unit
interface Reframer {
  reframeImage(input: Buffer, target: {width:number; height:number}): Promise<Buffer>;
}

// real impl consumes the built package (injected clients):
OutpaintReframer:  detectSourceSpec → runPhase1Once(genai,…) → runPhase2ForTarget(openai,…, 1080×1920) → Buffer
// no-network fake for the offline suite:
FakeReframer:  sharp-resize/pad input → target  (deterministic, zero API)
  • Eyeball CLI: npm run reframe -- <image> → outpaint to 1080×1920 → out/reframe/<name>-9x16.png. Needs GEMINI_API_KEY + OPENAI_API_KEY. Human judges whether the vertical extension looks natural.
  • Tests stay offline: FakeReframer contract test + OutpaintReframer with injected fake genai/openai clients. The package itself is already covered by functions' 80 tests.
